A unit named by net id was decoded with the class's table and looked up in the champion run, so the name is read rather than guessed. One named by shape is a unit the table cannot reach yet: it keeps its obfuscated key, and its team comes from which fountain it visits.

Minimap from Riot's Data Dragon (map11.png, 16.20.1). Map coordinates −120…14870 across, −120…14980 down. Fog: which units a side could see is read from the replay's own visibility packets, and so is which side owns a unit. Movement: a packet is a click, not a position — it carries the path asked for and the unit's speed, and the unit is usually interrupted before arriving, so units are walked along their path at their own speed. How far a unit sees is not in the file, so the radii are the game's documented ones — 1350 for a champion, 1200 for a minion. Terrain is not modelled: walls block sight in the game and do not here, so the lit patches are round where they should be ragged.
